# Portfolio Web de Serrana Calvo

Portfolio moderno estilo oscuro creado con Node, React y Vite.

## Estructura

- `src/` - código de React
- `public/` - HTML base
- `server.js` - servidor Express que sirve la app construida

## Scripts

- `npm install` - instala dependencias
- `npm run dev` - ejecuta la app en modo desarrollo
- `npm run build` - genera el bundle de producción
- `npm start` - arranca el servidor Express en `http://localhost:3000`

## Notas

Esta aplicación incluye:

- diseño oscuro y limpio
- secciones de proyectos, experiencia, educación, certificaciones y contacto
- contenido basado en el CV profesional proporcionado
